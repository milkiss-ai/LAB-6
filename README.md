# Поиск фильмов — лабораторная работа №6

Одностраничное приложение на React (Vite) + OMDb API: поле ввода, кнопка «Найти»,
список карточек с постером, названием и годом, состояния загрузки / ошибки / пустого
результата, заглушка вместо отсутствующего постера и блокировка повторных запросов.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173).

## Ключ OMDb

1. Зайдите на https://www.omdbapi.com/apikey.aspx
2. Выберите **FREE! (1,000 daily limit)**, укажите email — ключ придёт на почту.
3. Впишите ключ в файл `.env`:

```
VITE_OMDB_API_KEY=ваш_ключ
```

4. Перезапустите `npm run dev` — Vite читает `.env` только при старте.

Без ключа приложение покажет понятную ошибку вместо падения.

## Структура

```

│   └── main.jsx
└── vite.config.js
```

## Как выполнены требования

| Требование | Реализация |
| --- | --- |
| Поле ввода + кнопка «Найти» | `<form onSubmit>` в `src/App.jsx`; круглая кнопка-лупа, работает и Enter |
| Карточка: постер, название, год | `src/MovieCard.jsx` |
| Состояния `idle / loading / error / success` | одно состояние `status` + отдельный `error` |
| «Ничего не найдено» | поле `Error` в ответе OMDb (`Movie not found!`) |
| Заглушка вместо постера | `Poster === 'N/A'` и `onError` → встроенный SVG-плейсхолдер |
| Запрет повторных запросов | кнопка `disabled` при `loading`, ранний `return` в `fetchMovies` |
| Уникальные `key` | `movie.imdbID` |
| Разбиение на компоненты | `App`, `MovieCard` |

Дополнительные задания (описание через `?i=imdbID`, пагинация, фильтр по году,
история в `localStorage`, автопоиск с debounce) не реализованы — по условию
работа выполнена до них.
